## Key Decisions

### 1. nodenext in the compat fixture
TS 6.0 allows bundler+commonjs, 5.9 rejects it (TS5095), so the fixture uses nodenext to run on both.

### 2. Stopgap is not shipped
`ignoreDeprecations: "6.0"` exists only so the suites run under 6.0.3; Phase 3 removes it. Phase 2 Entry state records the TS5103 caveat.

### 4. ADR-0002: paths absolute, no baseUrl, node10 downgrade version-gated
See `docs/adrs/0002-tsc-adapter-path-resolution-without-baseurl.md`. Absolute `paths` because without baseUrl TypeScript resolves relative paths against `pathsBasePath` (user tsconfig paths) or `process.cwd()`. The node10 downgrade is gated rather than removed because 5.x rejects bundler+commonjs (TS5095) and the supported range stays >=5.7 <7. Issue 3 consolidation deliberately not folded in.

### 5. rootDir pinned to the common source directory (flagged, ADR not yet written)
When the user omits rootDir, TSF pins it to the 5.x-style inferred common source directory rather than adopting 6.0's tsconfig-directory default, so emit layout is identical across versions. ADR-worthy; no user confirmation was available, so the ADR is not written. Tracked as issue 8.

### 3. TS 6.0 compiler API is 5.9-compatible
No API-level failures anywhere; all breaks are config-level (injected `baseUrl`, node10).

Note: ADR-0002 was written this session (Phase 2). npm `latest` for typescript is 7.0.2, so installs must pin `~6.0.3`.
