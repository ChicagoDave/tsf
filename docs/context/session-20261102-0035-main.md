## Key Decisions
### 1. TypeScript 7 adoption: not now
TS 7 removed the JS compiler API TSF depends on (createProgram, emit, getPreEmitDiagnostics, readConfigFile, parseJsonConfigFileContent, transpileModule, ts.sys across src/compilers/tsc.ts, src/compilers/esbuild.ts, src/transform/imports.ts, src/transform/declarations.ts, src/compilers/rollup-bundler.ts). 7.1 beta (2026-10-20) offers an unstable new API under typescript/sync, /async, /fs, /ast. TSF's tsc adapter injects `baseUrl` and downgrades moduleResolution to `node10`, both hard errors in TS 7; its own tsconfig uses commonjs + node. Pinned ^5.7.0 (5.9.3 installed), never crossed 6.0. Recommendation: new plan for TS 6.0 compatibility (replace baseUrl/node10 injection with tsconfig-relative paths + bundler resolution), then spike the 7.1 API behind the adapter interface once stable (~December 2026). ADR-worthy when that work starts; no ADR written this session.
