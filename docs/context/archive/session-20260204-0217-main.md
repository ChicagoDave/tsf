### Key Insights from Documentation Process

**Import Rewriting Complexity**:
The `transform/imports.ts` module handles multiple import styles:
- Named imports: `import { foo } from '@scope/pkg'`
- Default imports: `import foo from '@scope/pkg'`
- Namespace imports: `import * as foo from '@scope/pkg'`
- Side-effect imports: `import '@scope/pkg'`
Each requires different regex patterns and replacement logic.

**Build Mode Distinction**:
TSF has two fundamentally different build modes:
1. **Local builds** (`tsf build`): Preserve workspace imports for local development
2. **npm builds** (`tsf build --npm`): Rewrite to relative paths for publishing

This distinction affects:
- Import resolution strategy
- Declaration file handling
- Output directory structure
- Package.json field generation

**Compiler Adapter Pattern**:
All compilers (tsc, esbuild, rollup) implement a common interface:
```typescript
interface CompilerAdapter {
  compile(opts: BuildOptions): Promise<void>
}
```
This allows pluggable compilation strategies while maintaining consistent orchestration.
