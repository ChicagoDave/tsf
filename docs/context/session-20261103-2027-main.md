## Key Decisions

### 1. ADR-0003: pin rootDir to the common source directory
When a user tsconfig omits rootDir, TSF decides it via `resolveRootDir()` (declared rootDir, else longest common directory of non-declaration inputs as TS 5.x inferred, else tsconfig dir). Every emitter pins it and every reader resolves through it; a declared rootDir is always honored. Scope: src/utils/tsconfig.ts, src/compilers/tsc.ts, src/compilers/esbuild.ts, src/transform/imports.ts, src/transform/declarations.ts, tests/ts6-compat.test.ts.
